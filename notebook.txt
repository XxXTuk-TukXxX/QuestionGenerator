What it should contain (practical checklist)
1) Project overview (1–2 pages)
Research question + hypothesis
What you built (one diagram of your pipeline is great)
Definitions of your key metrics (learning gain, repeat-error rate, time-to-mastery)
2) Daily/weekly work log (the “journal” part)
For each session/date:
What you tried
What changed (code, data, prompts, parameters)
What worked / what failed (judges explicitly want failures noted)
Short results or observations
Next steps
3) Experiment record
Study design: control vs treatment, timing, number of questions, etc.
Data collection plan + any consent/permissions if you test with people (keep the actual signed forms off the display and out of the notebook you show)
Raw results tables (or printed summaries) + how you computed metrics
4) Technical appendix (for CS projects)
System architecture (modules + data flow)
Data schema (what you log per attempt)
Key algorithms (adaptive scheduler logic, validation rules)
Ablations / comparisons (adaptive vs non-adaptive, fine-tuned vs base)
5) Bibliography
List sources you used (papers, docs, websites, models/datasets). NMSEF explicitly expects a bibliography in the notebook.
