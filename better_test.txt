2) Make distractors actually diagnostic (MCQ)
Common LLM problem: wrong answers are obviously wrong, or just random numbers.
Improve by:
generating distractors from known misconceptions (“sign error,” “confuse correlation/causation,” “drops a negative,” “uses mean vs median,” etc.)
requiring each distractor to come with a label: what mistake it represents.
3) Control difficulty on purpose (not by vibes)
Common LLM problem: “medium” difficulty is inconsistent.
Improve by:
using a difficulty dial tied to features: steps needed, number of concepts, amount of computation, inference distance, reading load
calibrating with real responses (even small pilots) so “medium” actually means “~60% correct” (or whatever target you pick).
4) Improve discrimination (separating strong vs weak students)
Common LLM problem: lots of items are either trivia or trick questions; neither discriminates well.
Improve by:
designing items where the key step requires the intended understanding
filtering with pilot stats: keep items where high-performers do much better than low-performers.
5) Better alignment + coverage (blueprinting)
Common LLM problem: it overfocuses on a few easy topics and misses standards.
Improve by:
creating a test blueprint (topic × skill × difficulty) and generating items to fill each cell
rejecting items that don’t map cleanly to a specific objective.
7) Make rubrics and partial credit consistent (FRQ)
Common LLM problem: rubrics are vague; grading is inconsistent.
Improve by:
generating a point-by-point rubric aligned to steps (1 pt setup, 1 pt method, 1 pt conclusion)
generating “anchor responses” (full credit, partial, common wrong) to stabilize grading.
10) Better feedback output (value beyond a score)

linking each wrong choice to a misconception + a targeted explanation/remediation
