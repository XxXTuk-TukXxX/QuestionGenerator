Draft Abstract (NMSEF/ISEF style, ~250 words)
This project investigates whether a mistake-adaptive study system built from a student’s real course materials improves learning outcomes compared to non-adaptive practice given the same study time. The system ingests a selected Canvas course module, caches the module’s files, and extracts study evidence from supported formats (PDF, DOCX, TXT, and Markdown). For PDFs, the pipeline performs layout analysis to separate text from visual regions (e.g., tables, graphs, diagrams, and equations). Visual regions are filtered to retain only instructionally useful figures. The system also constructs a module-specific misconception bank by mining common misconceptions from web sources, verifying them against quoted evidence, and clustering duplicates using embeddings. Using the extracted evidence, figures, and misconception bank, the program generates multiple-choice questions (MCQs) aligned to a blueprint spanning topic × skill × target difficulty. Each question includes source citations (file and page, and figure ID when image-grounded) and distractor diagnostics linked to misconception identifiers. Post-generation validation checks enforce structural correctness, blueprint alignment, and diagnostic validity.
To evaluate learning impact, participants study the same module content and are randomly assigned to either an adaptive condition, in which the next question is selected based on concept mastery inferred from prior responses, or a non-adaptive condition, in which questions are sampled without using response history. Both groups complete a pre-test, a fixed-length practice session, and a post-test matched for content coverage and difficulty. Primary outcomes include score improvement, repeat-error rate on previously missed concepts, and time-to-mastery per concept. Results will quantify whether mistake-adaptive scheduling combined with evidence-grounded question generation produces measurable gains in learning efficiency and retention.
